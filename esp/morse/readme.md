# ESP Morse

Небольшой эксперимент с JavaScript на ESP8266 с использованием Espruino. Текущий код принимает заранее заданную строку в формате азбуки Морзе и последовательно передаёт её с помощью светодиода на GPIO2. Изначально в коде зашифрована фраза **`I FUCKING HATE JAVA.`**. Точка (`.`) включает светодиод на `1T`, тире (`-`) — на `3T`, пробел задаёт паузу между буквами, а `/` — паузу между словами. В качестве базового интервала используется `T = 100 мс`, а выполнение передачи управляется через `setInterval()`.

## Запуск

Подключите ESP8266 к компьютеру и прошейте его Espruino. После подключения к плате через Espruino Web IDE выполните код в консоли. Передаваемое сообщение изменяется непосредственно в переменной `str`. Светодиод подключён к GPIO2 и работает в активном низком уровне: `digitalWrite(2, 0)` включает его, а `digitalWrite(2, 1)` выключает.
